# デザインコンセプト｜株式会社ペイントホーム サイトリニューアル提案

## コンセプト：**色は、家のどこを指すか**

> 塗装屋のサイトなのに、色に意味がないのは変だ。
> このサイトの色は、飾りではなく「いま家のどこの話をしているか」を指している。

ご要望は「カラフルさを最大の強みとして押し出す／ポップで元気な会社だと一瞬で伝わる」。
ただし色数を増やすだけでは、量産のテンプレートサイトと同じ見た目になる。
そこで **色に役割を固定し、サイト全体を1つのルールで運用する** ことにした。

既存サイト（paint-home.co.jp）の主要色 `#0B85C8` を主役に据えたのは、リニューアル後も
「同じ会社だ」と分かることを優先したため。差し色3色は、御社の事業区分（塗装・防水・
リフォーム・外まわり）をそのまま色に写している。

## 1. 色 ― メイン1色＋差し色3色

| トークン | 色 | 指すもの | 根拠 |
|---|---|---|---|
| **水色（メイン）** | `#0B85C8` | 壁（外壁塗装・サイディング・シーリング）／会社そのもの | 既存サイトの主要色をそのまま継承 |
| 濃水色 | `#04618F` | 水色の一段深い側。グラデーションと文字色に使用 | 同一色相の明度違い |
| **山吹** | `#F7A600` | 屋根（屋根塗装・屋根板金） | 札幌の家でいちばん陽と雪を受ける面＝いちばん強い色 |
| **若草** | `#37A75C` | 床・外まわり（防水・外構・融雪槽・車庫） | ウレタン防水の塗膜が緑。実物から借りた色 |
| **朱** | `#E8462B` | 室内（クロス・キッチン・浴室・サッシ） | 家の「中」だけに使う暖色 |
| 紺 | `#06293D` | 濃色面（職人の構成・施工事例） | 白基調を締める。2セクションのみ |
| 墨 | `#16202A` | 本文・フッター | |
| 霧 | `#F4F8FB` | 薄面 | |

**運用ルール**
- ページ面積の70%以上は白と水色。差し色は該当する工事の話をしているときだけ出す
- 4色が同時に並ぶのは3か所だけ（ロゴマーク／特殊塗装の色帯／ヒーロー下とフッターの帯）＝「会社全体を指す場所」の合図
- セクション背景を淡色で交互に塗り分けない（テンプレ感の主因）
- グラデーションは2種類しか定義しない
  - `--grad-sky`（#04618F → #0B85C8 → #3FA9E5）：同一色相の明度変化。CTAのみ
  - `--grad-warm`（#E8462B → #F7A600）：隣接色相のみ。採用セクションのみ
  - 角度は両方 **38deg に固定**。ローラーを下から上へ押し上げる手の角度に揃えた
  - 虹グラデ・多色グラデ・意味のない背景グラデは0か所

## 2. 書体 ― ゴシック1系統＋数字は等幅

明朝は使わない。「ポップで元気」を、書体の格ではなく **太さと大きさのコントラスト** で出す。

- 見出し・本文：`"Hiragino Sans","Yu Gothic Medium",…`（weight 800 と 400 の2段だけ）
- 数字・英字・色番号：等幅（`--mono`）。電話番号・年数・HEX値の質感を本文から切り離す
- Webフォント不使用（読み込み待ちゼロ、環境依存の崩れなし）

**文字サイズの4階層**

| 階層 | サイズ | 用途 |
|---|---|---|
| 山 | `clamp(30px,5.6vw,60px)` | ヒーロー主見出しのみ（「うち」だけ 1.16em） |
| 大 | `clamp(20px,4.4vw,48px)` | セクション見出し（3型を使い分け） |
| 標準 | `15〜17.5px` | リード文 |
| 資料 | `11〜13.5px` | 注記・チップ・撮影メモ |

## 3. レイアウト ― 非対称を意図的に置く

- ヒーロー：ご提供のメインビジュアル（`img/main-img-full2.jpg`）を全面に敷き、
  左寄せ1カラムでコピーを置く。写真は2000×400の横長なので `object-position:78%` で
  **虹色の刷毛が必ず画面に入る位置**を固定し、文字側には白のスクリムを重ねる
  （黒の半透明オーバーレイは色が濁るため不使用。写真自身の白フェードと同じ白で伸ばす）。
  幅900px以下は72%、760px以下は70%＋縦方向スクリムへ切り替え
- 色ルール：**1:1.12**（左に説明＋家の断面図、右に4色の役割リスト）
- 自社施工：写真の上に黄色のタグを重ね、グリッドの外へはみ出させる
- 業務内容：**主力2件（外壁・屋根）だけ「大きな写真＋文章」**で、写真の左右を入れ替えて
  1.18:1 ↔ 1:1.18 と比率も反転させる。残り5件は罫線もカードも使わない索引に落とす
- 施工事例：**代表1件をフル幅**（1.6:1）、残り5件は 6カラムに `span2 × 3 → span3 × 2` で
  3+2 のリズム。等分割にしない
- 見出しの型を6種類使い分け、「ラベル＋大見出し＋3カード」の反復を1度もしない
- 角丸はほぼ全廃（色見本・塗料缶・足場は直角）。角丸ピル型バッジを多用しない

**ただし機能面は定石を維持（ご指示どおり）**
- FAQ：`<details>` のアコーディオン、1つだけ開く
- フォーム：縦積みラベル＋必須/任意バッジ＋同意チェック＋確認ボタン。既存サイトの
  入力項目（件名・お名前・ふりがな・郵便番号・住所・電話・メール・内容）を踏襲

## 4. 文章のルール

**禁止**
- 「〜を実現します」「お気軽に」「安心」「高品質」「豊富な実績」「お客様に寄り添う」
  （既存サイトにある「お気軽にお問い合わせください」もあえて置き換えた）

**遵守**
- 抽象語は数字と固有名詞に置き換える
  - 「実績豊富」→「1995年から31年目」「職人19人」「40代13名」
  - 「安心の自社施工」→「見積りを書いた人間が、そのまま現場に立ちます」
  - 「万全なアフターサポート」→「終わったあとも同じ番号につながる」
- 短文と長文を混ぜる（「下請けに出しません。」の直後に長い説明を置く）
- 都合の悪いことも書く（冬は外部塗装不可／当日中に金額は出さない／保証年数を口頭で
  約束しない／見積り後に断ってよい）
- 実在情報（社名・住所・電話・FAX・許可番号・設立・代表者・事業内容・採用条件）は
  既存サイトの記載をそのまま踏襲。記載のない情報（保証年数・価格・施工件数）は
  **創作せず**、「見積書に明記します」の表現で処理

## 6. 写真（ダミー方針）

実写はファーストビューのメインビジュアル（`img/main-img-full2.jpg`／ご提供画像）1点のみ。
残りは**差し替え枠＋撮影メモ**で構成した。フリー素材・生成画像は使用していない。

枠は全部同じにせず、**撮ってほしい画の種類ごとに4種**に分けている。同じ処理の反復を防ぐと
同時に、撮影を依頼するときの指示書としてそのまま使えるようにするため。

| 種類 | 比率 | 見た目 | 使う場所 |
|---|---|---|---|
| `-wide`（引き） | 16:9 | 淡色ベタ、メモは下 | 主力2件、代表事例、店舗・外構 |
| `-close`（寄り） | 4:3 | 罫線のみ・下地なし、メモは右下 | 小さい事例3件 |
| `-tall`（縦） | 3:4 | 淡色ベタ | 人物（集合写真） |
| `-sq`（正方） | 1:1 | 淡色ベタ | 本社外観・ポートレート |

図版（家の断面図・ロゴマーク）はHTML内のSVGで自作。外部フォント／CDN／外部スクリプトへの
依存はゼロ。

**残した色ブロックと、その理由**

以下は「装飾」ではなく**それ自体が情報**なので残した。いずれもサイト内で1回だけの処理。

- 色のルールの色見本（`.rule-sw`）… 色の定義そのもの。これを消すとセクションが成立しない
- 施工可否表（`.cal-row i`）… 12か月×4区分のデータ
- 職人の年代構成（`.dots i`）… 20人の内訳データ
- ヒーロー下端とフッターの4色帯… 「会社全体を指す場所」の合図（全幅の帯であり、見出し上の短い罫線ではない）
